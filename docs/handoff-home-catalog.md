# 引き継ぎ資料 — ホーム品揃え問題の修正（HonestBaby）

最終更新: 2026-06-18 / ブランチ: `main`（全コミット済み・作業ツリーclean）

## 1. 背景・最初の依頼
ホーム（サイトの要）で **サブカテゴリが空・商品が薄い・定番すら入っていない** 状態が続いていた。
ユーザーは「確実な作業」「新しい方法」「類似比較サイトのやり方の参考」を要望。
途中で追加報告: **(a) まだ空のサブがある (b) 全く関係ない商品が混ざっている**。

## 2. 根本原因（実データで確定済み — 推測ではない）
当初の「楽天API死亡」仮説は **誤り**。Supabase MCPで実データを見て訂正した。
真因はホーム表示側にあった:

1. **【主因】ホームが商品を全件読めていなかった。** `src/App.jsx` の `fetchProducts` が
   `.order()` もページングも無し → Supabase既定 **Max Rows=1000** に対し表示可1,600件超あり、
   約600件が読まれず、順序も不定。これが「サブが空・定番が無い」の正体。
2. **サイズ/月齢タブが常に空。** `products` に `sub_sub_category` 列が**存在しない**のに
   `p.subSubCategory === selected` で絞っていた。
3. **一部サブが真に0件**（キーワードが長すぎるAND検索で0ヒット／60秒締切スキップ）。
4. **無関係商品の混入**（ペット用品/大人・介護用品/蚊帳/ノイズ名商品）。
5. cronがエラーを握りつぶしHTTP200を返す（可視性ゼロ）。

⚠️ **楽天検索APIは `Search/20220601` で正常稼働中。バージョンを上げてはいけない（動作中の系を壊す）。**

## 5. 毎日の更新の仕組み（ユーザーに説明済み）
- 夜間cron 15バッチが **増分upsert**（`rakuten_item_code` 一致で更新、新規はinsert）。
  **delete/truncate は一切なし** → 既存商品は残り、価格・評価・ランクが更新される。
  今夜の検索に出てこなかった商品も**消えない**。is_blockedはblockedのまま。
- **手動でバッチを回す必要はない**。cronが自動維持する。
- ⚠️ 既知の限界（未実装・任意の将来課題）: 廃番・古い商品を自動で隠す仕組みは無い。
  「N日見つからない商品を自動非表示」ルールは提案のみで未着手。

## 6. ユーザー検索→DB自動追加機能（現状: そのまま稼働中）
- 検索ボックス → `fetchRemoteProductsWithAI`（src/App.jsx:1690）が楽天/Yahoo取得→Gemini厳選→表示
- 直後に `autoSaveSearchResultsToDb`（src/App.jsx:1651）が結果を `products` に
  `upsert`（`onConflict: 'name', ignoreDuplicates: true`）で保存 = **全ユーザー共有**
- カテゴリタブの `fetchRankingsWithAI` も同じ保存関数を呼ぶ
- 今セッションでこの経路は**一切変更していない** → 機能は以前のまま維持
